## 📌 Overview

The **Nexus Banking App** is a secure and efficient **Java-based desktop application** designed to offer seamless digital banking services.
It provides users with features like **account management, fund transfers, bill payments, ATM transactions, and enhanced security using OTP verification**.

---

## 🚀 Features

* 🔐 **User Authentication**

  * Secure login with **4-digit PIN**
  * New user registration and profile management

* 💸 **Send Money**

  * Transfer funds to other accounts
  * **OTP verification via email** for transaction security

* 🧾 **Bill Payments & Top-Ups**

  * Easy and quick bill payments and mobile recharges

* 🏧 **ATM Transactions**

  * Deposit, withdraw, fast cash, balance inquiry, and mini statements

* ⚙️ **Settings & Security**

  * Change PIN, planned fingerprint authentication, and logout options

* ⭐ **Feedback System**

  * Star ratings and detailed feedback for service improvement

---

## 🛠️ Tech Stack

* **Frontend:** Java Swing, JFrame
* **Backend:** Java (Core Java OOP concepts)
* **Database:** MySQL
* **Security:** OTP verification, encrypted data handling
* **Environment:** Windows/Linux (2GB RAM, dual-core processor minimum)

---

## ⚙️ How to Run

1️⃣ **Clone Repository**

```bash
git clone https://github.com/username/nexus-banking-app.git
cd nexus-banking-app
```

2️⃣ **Setup Database**

* Import `nexus_db.sql` into your MySQL server
* Update DB credentials in `DatabaseConnection.java`

3️⃣ **Run Application**

* Open the project in **IntelliJ / Eclipse / NetBeans**
* Compile and run `Main.java`
